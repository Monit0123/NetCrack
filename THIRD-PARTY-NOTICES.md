### `Samples/netcrack-demo.pcap`, `Samples/netcrack-demo.22000`

Generated by `Scripts/make_sample_capture.py`. Synthetic frames for a fictional
network (`NetCrack-Demo` / `password1`); contain no third-party data and no real
network captures.

## Tools NetCrack invokes (not redistributed)

NetCrack drives these binaries at runtime. They are **not** bundled, and each
keeps its own licence:

| Tool | Licence | Project |
|---|---|---|
| hashcat | MIT | <https://hashcat.net/hashcat/> |
| hcxtools (`hcxpcapngtool`) | MIT | <https://github.com/ZerBea/hcxtools> |
| aircrack-ng (`aireplay-ng`, `wash`, `aircrack-ng`) | GPL-2.0 | <https://www.aircrack-ng.org/> |
| reaver | GPL-2.0 | <https://github.com/t6x/reaver-wps-fork-t6x> |
| tcpdump / libpcap | BSD-3-Clause | <https://www.tcpdump.org/> |
| Homebrew | BSD-2-Clause | <https://brew.sh/> |

Apple frameworks used: SwiftUI, AppKit, CoreWLAN, CoreLocation, CoreGraphics,
IOKit (`IOPMAssertion`), Foundation.

`hashcat`'s `best64.rule` is referenced by name only; it ships with hashcat in
`/opt/homebrew/share/hashcat/rules/` and is not redistributed here.
